<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Third-party renderer to app DOM | OSMD/Verovio writes SVG/DOM into the app's notation area |
| User MusicXML to renderer parser | Uploaded XML/MXL data enters third-party parsing/layout code |
| External fixture suite to repository | Third-party test files become project fixtures |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01-01 | Tampering | Renderer DOM output | mitigate | Insert renderer output only into a controlled container and keep app interactions behind facade-controlled event delegation. |
| T-06-01-02 | Denial of Service | Large MusicXML rendering | mitigate | Measure render time in smoke and document fixture/size limits for imported scores. |
| T-06-01-03 | Information Disclosure | Local imported scores | mitigate | Keep all imports local; do not fetch or upload user score content for rendering. |
| T-06-01-04 | Repudiation | Fixture licensing | mitigate | Store license/notice with vendored fixtures and record source commit/URL in manifest. |
</threat_model>
