<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| Canonical playback to visual renderer | App-owned event data is joined to third-party renderer output. |
| Score click targets to practice controls | User actions on generated SVG influence playback range and start state. |
| XML preprocessing to OSMD input | Optional ID injection modifies inert XML before rendering. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-02-01 | Tampering | Event mapping | mitigate | Fail or warn on ambiguous mapping instead of assigning wrong visual targets silently. |
| T-07-02-02 | Repudiation | Renderer diagnostics | mitigate | Include mapping diagnostics in render results and test failures so gaps are attributable. |
| T-07-02-03 | Denial of Service | Mapping large scores | mitigate | Keep mapping linear where possible and avoid repeated whole-score remaps during playback. |
| T-07-02-04 | Information Disclosure | XML preprocessing | mitigate | Keep preprocessing local and do not serialize user score data outside the browser. |
</threat_model>
