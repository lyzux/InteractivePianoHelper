<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| uploaded MusicXML to browser parser | Untrusted file data enters the static app |
| browser app to IndexedDB | Untrusted imported text is persisted locally |
| renderer dependency to DOM | Third-party or adapter renderer writes SVG/DOM into the page |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01-01 | Tampering | js/importedScoreStore.js | mitigate | Persist only inert text/metadata records and never executable code or dynamic imports from user files. |
| T-05-01-02 | Elevation of Privilege | js/musicXmlScoreRenderer.js | mitigate | Forbid eval, Function, inline script execution, and static-image-only renderer shortcuts. |
| T-05-01-03 | Denial of Service | renderer gate | mitigate | Gate records large-score/performance limits and requires browser smoke to finish under the test timeout. |
</threat_model>
